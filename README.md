# Web Design Integration

Static HTML and CSS implementation of the supplied furniture catalogue mockups.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Project contents

- `index.html` — semantic catalogue markup and temporary product data
- `styles.css` — desktop layout and mobile CSS Grid breakpoint
- `assets/` — supplied interface icons and product images cropped from the provided desktop mockup

The page uses Avenir when available on the device and imports Roboto from Google Fonts, as the supplied brief requests. No Avenir font file was included in the provided assets.

The design is a static integration: search, sorting, cart buttons, and pagination are visual placeholders and are not connected to a store.

## GitHub

This folder is a local Git repository. To publish it, create a GitHub repository and add its URL as the `origin` remote before pushing.
