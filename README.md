# Intégration web — catalogue de meubles

Exercice d’intégration donné par le responsable pédagogique de la formation, à partir du sujet C-DEV-113 fourni par Epitech. L’objectif est de reproduire les maquettes desktop et mobile d’un catalogue de meubles avec HTML5 et CSS3.

## Consigne

- Intégrer la maquette ordinateur et la maquette mobile.
- Construire la mise en page responsive avec CSS Grid.
- Utiliser une structure HTML sémantique et soigner le référencement naturel.
- Reprendre au mieux les polices et les visuels indiqués dans les maquettes.

## Lancer le projet

Ouvrir `index.html` dans un navigateur. Aucun outil de compilation ni installation de dépendances n’est nécessaire.

## Fichiers

- `index.html` : structure de la page et données temporaires des produits.
- `styles.css` : styles desktop et adaptation mobile.
- `assets/` : icônes fournies et images des produits extraites de la maquette.

Roboto est importée depuis Google Fonts. Aucune police Avenir n’étant incluse dans les ressources fournies, elle est utilisée si elle est disponible sur l’appareil, avec une police de remplacement sinon.

La page est une intégration statique : recherche, tri, panier et pagination sont visuels et ne sont pas reliés à une boutique.

## Git et publication

Le projet est suivi dans un dépôt Git local. Aucun dépôt GitHub distant n’est configuré ; il faudra ajouter l’URL d’un dépôt GitHub comme remote `origin` pour le publier.
